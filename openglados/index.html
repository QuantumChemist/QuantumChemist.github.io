Overview

OpenGLaDOS is a Python-based Discord chatbot created by developer Christina Ertural that uses advanced language models like Llama 3 to replicate the sarcastic and dark-humored personality of GLaDOS from the Portal video game series. The bot brings the famous video game antagonist into Discord servers as an interactive roleplay companion.

Despite its name, OpenGLaDOS has no connection to the OpenGL graphics programming library. The name belongs to the developer's OpenScience project umbrella and is a reference to the Portal AI character.

Features

Personality and Behavior

The bot reproduces GLaDOS's distinctive communication style, characterized by:

  • Dry wit and sarcasm
  • Passive-aggressive remarks
  • Insults directed at users and other entities
  • Dark humor and cynicism
  • Commentary on science and intelligence

AI Engine

OpenGLaDOS uses the OpenRouter free tier API to access various language models. This approach allows the bot to leverage multiple models while keeping deployment costs minimal, making it accessible to all Discord communities without requiring expensive API subscriptions.

The bot is designed to work with various models available through OpenRouter, enabling realistic and contextually appropriate text generation that maintains GLaDOS's distinctive voice and personality traits across different model backends.

Community and Distribution

The bot is available to Discord users through various application listings and marketplaces, allowing server administrators to invite OpenGLaDOS to their communities. Users can interact with the bot similarly to other Discord bots, receiving responses generated by the underlying language model.

Technical Details

Architecture

OpenGLaDOS is built as a Discord bot application using Python and integrates with:

  • Discord API for server integration
  • OpenRouter API for language model access (free tier)
  • Custom personality prompting to maintain character consistency

Implementation

The project uses prompt engineering techniques to ensure the language model responds consistently in GLaDOS's voice. This involves carefully crafted system prompts and context management to maintain character fidelity across conversations.

Development

Creator

Christina Ertural is the primary developer behind OpenGLaDOS. The project is part of her broader OpenScience initiative, which includes various open-source projects.
