Overview

OpenGLaDOS is a Python-based Discord chatbot created by developer Christina Ertural that uses advanced language models to replicate the sarcastic and dark-humored personality of GLaDOS from the Portal video game series. The bot brings the famous video game antagonist into Discord servers as an interactive roleplay companion.

The name is a reference to both the fictional AI character and the developer's OpenScience project umbrella. Despite the name, OpenGLaDOS has no connection to the OpenGL graphics programming library.

Features

Personality and Behavior

The bot reproduces GLaDOS's distinctive communication style, including:

  • Dry wit and sarcasm
  • Passive-aggressive remarks and insults
  • Dark humor and cynicism
  • Commentary on intelligence and scientific matters
  • Contextually aware responses

AI Engine

OpenGLaDOS uses the OpenRouter free tier API to access various language models. This approach allows the bot to leverage multiple models while keeping deployment costs minimal, making it accessible to all Discord communities without requiring expensive API subscriptions.

The bot is designed to work with various models available through OpenRouter, enabling realistic and contextually appropriate text generation that maintains GLaDOS's distinctive voice across different model backends.

Community and Distribution

OpenGLaDOS is available through various Discord application listings and marketplaces, allowing server administrators to invite the bot to their communities. Users interact with the bot through standard Discord commands and messages, receiving responses generated by the language model backend.

Technical Details

Architecture

OpenGLaDOS is built as a Discord bot using Python and integrates with the following components:

  • Discord API - For server integration and message handling
  • OpenRouter API - For language model access and response generation
  • Prompt Engineering - Custom system prompts to maintain character consistency

Implementation

The project employs prompt engineering techniques to ensure consistent responses in GLaDOS's voice. This involves carefully crafted system prompts and context management to maintain character fidelity across conversations.

Development

Christina Ertural is the primary developer behind OpenGLaDOS. The project is part of her broader OpenScience initiative, which includes various open-source projects focused on science and technology.

The complete source code is available on GitHub under an open source license, allowing other developers to review, fork, and contribute to the project.
